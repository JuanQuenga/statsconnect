About StatsConnect

Last updated October 6, 2026.

StatsConnect is a fan-made statistics hub for Clash Royale and Brawl Stars. It brings player lookup, leaderboards, live meta analysis, and practical tools for both games into one place, with one account and one saved-profile list across all of them.

What you can do here

  • Look up any player by tag and review trophies, battles, decks, and progression.
  • Browse official leaderboards with real historical movement, not just today’s snapshot.
  • Read meta reports built from public battle logs, with sample sizes shown next to every number.
  • Use tools built around each game: deck discovery and war sets for Clash Royale, a progression planner and map assistant for Brawl Stars.
  • Learn deck archetypes from strategy guides that link straight into live data.

How it works

StatsConnect reads public game data through the official Supercell developer APIs and community data services, and runs its own crawlers that fold public battle logs into daily aggregates. Nothing here uses private account data, and nothing requires your game login. The details — sources, refresh cadence, and limitations — are documented on the data & methodology page.

Who builds it

StatsConnect is built and operated by Juan Quenga, an independent developer. It is a small, actively maintained project — if something looks wrong, telling me about it genuinely helps.

How it is supported

StatsConnect is free to use. Running live data pipelines, crawlers, and hosting costs real money, so the project is supported by optional contributions and, over time, unobtrusive advertising. Contributions are completely voluntary and unlock nothing — every feature works the same for everyone. The privacy policy explains what data advertising and analytics involve.

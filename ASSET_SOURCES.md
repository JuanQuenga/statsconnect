# Asset Sources

This static demo uses recovered local assets plus current Brawl Stars assets served by Brawlify.

## GitHub-backed CDN

- Repository: https://github.com/Brawlify/CDN
- CDN base: https://cdn.brawlify.com
- License: MIT for the CDN repository; Supercell fan content rules still apply.

Useful folders used by the demo:

- `brawlers/borders/{id}.png`
- `brawlers/model/{id}.png`
- `club-badges/regular/{id}.png`
- `game-modes/regular/{id}.png`
- `maps/regular/{id}.png`

## Current Metadata Reference

- BrawlAPI brawler metadata: https://api.brawlapi.com/v1/brawlers

The home page uses current brawler IDs and names from BrawlAPI as mock demo records. Trophy totals, win rates, events, timers, and club data are presentational mock data, not live API responses.
